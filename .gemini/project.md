# Project: Primetek HR Portal

## Scope & Purpose
Primetek HR Portal is an enterprise-grade employee time-tracking and job application management platform. It includes automatic status tracking, geofenced client-site check-ins, offline recovery synchronization, PWA push notifications, and administrative approvals pipelines.

## Tech Stack
- **Frontend**: Next.js 14+ (React App Router, TypeScript, Tailwind CSS, Framer Motion)
- **Database**: Supabase (PostgreSQL with RLS policy enforcement)
- **APIs & Integrations**: Resend Mail API, Web Push notifications, Chrome Extension telemetry integration
- **Testing**: Vitest (Unit/Integration), Playwright (End-to-End)
